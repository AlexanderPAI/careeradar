# Release Notes v.0.3.0

`v.0.3.0` добавляет авторизацию, изоляцию данных по владельцам и выбор между GigaChat и OpenRouter.

### Что вошло в релиз

- Добавлена модель пользователя с уникальным логином, хешем пароля и флагом активности.
- Реализован вход через OAuth2 password flow с JWT access token.
- Все основные API и страницы Streamlit закрыты авторизацией.
- Добавлены форма входа, отображение текущего пользователя и выход из сессии.
- Профили кандидатов и запуски поиска привязаны к владельцу; API проверяет право доступа к каждому объекту.
- История профилей, подборов и вакансий фильтруется по текущему пользователю.
- Добавлен CLI-скрипт для создания пользователей без публичной регистрации.
- Добавлены Alembic-миграции для учётных записей, владельцев данных и сохранения поискового запроса в профиле.
- Существующие до миграции данные изолируются под отключённой служебной учётной записью.
- Сохранённый поисковый запрос используется для первого и повторного подбора со страницы профиля.
- Введён общий интерфейс LLM-провайдеров и фабрика выбора провайдера через `LLM_PROVIDER`.
- Добавлен GigaChat-адаптер с OAuth-токеном, кешированием, обновлением токена и повторными попытками при временных сбоях.
- Агенты анализа резюме, поиска и фильтрации переведены на общий LLM-адаптер.
- Обновлены `.env.example`, Docker Compose и сетевая схема: frontend больше не имеет прямого доступа к PostgreSQL.

### Цель релиза

Главная цель `v.0.3.0` — подготовить КарьеРадар к безопасной многопользовательской работе и убрать жёсткую привязку AI-агентов к одному LLM-провайдеру.

Релиз должен обеспечить:

- вход по JWT без публичной регистрации;
- доступ только к своим профилям, поискам и результатам;
- создание учётных записей администратором;
- переключение между GigaChat и OpenRouter через конфигурацию;
- единую обработку ошибок LLM-провайдеров.

### Что пока не входит в релиз

- Публичная регистрация и самостоятельное восстановление пароля.
- Роли и разграничение административных прав.
- Редактирование, удаление и архивирование профилей через UI.
- Просмотр полной истории всех подборов одного профиля.
- Настройка источников вакансий и LLM-провайдера из UI.
- Автоматическая отправка откликов работодателям.
- Production-ready мониторинг, резервное копирование и управление секретами.

### Статус релиза

`v.0.3.0` сохраняет сценарии поиска и повторного подбора, добавляя многопользовательскую изоляцию и выбор LLM-провайдера.
