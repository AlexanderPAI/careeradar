# Release Notes v.0.4.0

`v.0.4.0` добавляет карьерные рекомендации по резюме, подробное сопоставление профиля с отдельной вакансией и историю таких анализов.

### Что вошло в релиз

- Добавлен агент `resume_advisor` с двумя сценариями: базовые рекомендации по резюме и анализ соответствия конкретной вакансии.
- На странице профиля появилась кнопка получения рекомендаций по резюме.
- Рекомендации формируются по сохранённому профилю и исходному тексту резюме без выдумывания отсутствующего опыта.
- Рекомендации сохраняются в PostgreSQL и повторно отображаются при открытии профиля.
- В выдаче вакансий появилась кнопка `Проверить соответствие` для каждой позиции.
- Добавлена загрузка полного описания отдельной вакансии с hh.ru и Хабр Карьеры.
- Анализ вакансии разделён на итоговую оценку, подтверждённые совпадения, пробелы и риски, вопросы для уточнения и рекомендацию по отклику.
- Результат анализа сохраняется вместе со снимком вакансии на момент проверки.
- Добавлены отдельные страницы списка анализов и детального результата сопоставления.
- История анализов изолирована по пользователям и доступна из общей навигации.
- Добавлены API-маршруты для рекомендаций по резюме, запуска анализа вакансии и просмотра истории анализов.
- Добавлены таблицы `resume_recommendations` и `vacancy_analyses` и соответствующие Alembic-миграции.
- Исправлено определение источника сохранённых вакансий по каноническим URL.
- Добавлена обработка недоступных, заблокированных и закрытых страниц вакансий.

### Цель релиза

Главная цель `v.0.4.0` — помочь пользователю не только найти подходящие вакансии, но и оценить готовность резюме и принять обоснованное решение об отклике.

Релиз должен обеспечить:

- персональные и практически применимые рекомендации по улучшению резюме;
- честное сопоставление фактического опыта кандидата с требованиями вакансии;
- явное разделение подтверждённых совпадений, рисков и данных, которые нужно уточнить;
- сохранение результатов для последующего возвращения к ним;
- приватность рекомендаций и анализов в многопользовательском режиме.

### Что пока не входит в релиз

- Автоматическое редактирование или переписывание резюме.
- Ручное редактирование профиля кандидата и рекомендаций.
- Анализ вакансии по произвольной ссылке вне сохранённой выдачи.
- Поддержка источников вакансий, кроме hh.ru и Хабр Карьеры.
- Сравнение нескольких вакансий между собой.
- Числовой процент соответствия профиля вакансии.
- Избранное, пользовательские статусы вакансий и трекер откликов.
- Автоматическая отправка откликов работодателям.

### Статус релиза

`v.0.4.0` сохраняет сценарии поиска, фильтрации и повторного подбора `v.0.3.1`, добавляя рекомендации по резюме и сохраняемую историю подробных анализов вакансий.
