# Release Notes v.0.1.0

`v.0.1.0` - самая первая версия КарьеРадара и MVP проекта.

### Что вошло в релиз

- Создан базовый backend на FastAPI.
- Создан frontend на Streamlit.
- Добавлен Docker Compose для запуска backend и frontend.
- Реализована загрузка резюме через UI.
- Добавлена поддержка резюме в форматах `.pdf`, `.docx`, `.doc`, `.txt`.
- Реализован агент анализа резюме `cv_analyzer`.
- Агент анализа резюме извлекает текст из файла и строит структурированный профиль кандидата.
- Реализована генерация поискового запроса на основе профиля кандидата.
- Реализован агент поиска вакансий `searcher`.
- Добавлен парсинг вакансий с hh.ru.
- Добавлен парсинг вакансий с Хабр Карьеры.
- Реализовано объединение результатов из разных источников в один CSV.
- Добавлена дедупликация вакансий по ссылке.
- Реализован агент фильтрации вакансий `vacancy_filter`.
- Фильтрация использует профиль кандидата и параметры вакансий.
- Добавлена батчевая обработка вакансий при фильтрации.
- Реализована выдача итогового CSV через API.
- В UI добавлен просмотр результатов в таблице.
- В UI добавлена кнопка скачивания CSV.
- Обновлен интерфейс: светлая палитра, вертикальные карточки профиля и единый блок статуса подбора.

### Цель релиза

Главная цель `v.0.1.0` - проверить полный путь от резюме до списка релевантных вакансий:

```text
резюме -> профиль кандидата -> поисковый запрос -> сбор вакансий -> фильтрация -> CSV
```

### Что пока не входит в релиз

- Авторизация пользователей.
- Сохранение истории поисков в базе данных.
- Редактирование профиля кандидата перед поиском.
- Настройка источников вакансий из UI.
- Расширенная аналитика по найденным вакансиям.
- Отправка откликов на вакансии.
- Production-ready деплой и мониторинг.

### Статус релиза

`v.0.1.0` считается MVP-релизом. Он пригоден для локального запуска, демонстрации основной идеи и дальнейшего развития продукта.
