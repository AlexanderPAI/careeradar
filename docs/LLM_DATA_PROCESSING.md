# Обработка данных внешними LLM

КарьеРадар использует внешнего поставщика большой языковой модели (LLM),
настроенного владельцем развёртывания. Без явного согласия пользователя backend
не запускает операции, передающие данные LLM.

## Какие данные передаются

Исходный файл резюме не передаётся. Из него локально извлекается текст, после
чего до отправки удаляются распознаваемые:

- имя в начале документа и подписанные строки с ФИО;
- телефон, электронная почта, ссылки и имена пользователей;
- адрес, дата рождения, гражданство и семейное положение;
- номера паспорта и СНИЛС.

Текст ограничивается 24 000 символами. Для последующих операций вместо полного
профиля формируется минимальный набор:

- для рекомендаций и сопоставления: позиции, навыки, уровень и длительность
  опыта, отрасли, языки, образование и обезличенное описание;
- для поиска дополнительно: зарплатные ожидания, формат работы, занятость и
  локация.

Имя, исходное имя файла, полный профиль, контактные данные и технические
идентификаторы пользователя LLM не передаются.

## Цели и управление

Данные используются только для построения карьерного профиля, поискового
запроса, фильтрации вакансий, рекомендаций и сопоставления с вакансией.
Согласие запрашивается перед каждой группой операций. Пользователь может не
давать или отозвать его, сняв отметку: новые обращения к LLM будут
заблокированы. Сохранённый профиль и связанные результаты можно удалить в
интерфейсе.

Срок локального хранения исходного файла и извлечённого текста задаётся
`RESUME_RETENTION_DAYS` и по умолчанию составляет 30 дней.
